Vos données restent chez vous

Dernière mise à jour : 4 octobre 2026

Ce qui reste sur votre ordinateur

Tout ce que vous saisissez dans Glowdesk : produits, prix, lots, ventes, clientes, utilisatrices et codes PIN. Ces données sont enregistrées dans un fichier sur votre ordinateur (avec ses sauvegardes) et ne sont jamais envoyées ailleurs. Les codes PIN sont stockés chiffrés (hachage Argon2).

Le peu qui est envoyé

  • Enregistrement gratuit (une fois) : le nom de la boutique, le nom de la propriétaire, le téléphone, la wilaya, la version de l'application et un identifiant d'installation aléatoire. Ils servent à créer votre licence gratuite, à vous informer des nouveautés et à recueillir vos retours.
  • À l'ouverture de l'application : l'identifiant d'installation, l'identifiant de la boutique et la version, pour vérifier la licence. Sans internet, l'application fonctionne normalement.
  • Mises à jour : l'application demande à GitHub s'il existe une nouvelle version. GitHub voit alors l'adresse IP de l'ordinateur, comme pour n'importe quel site.

Aucune publicité, aucun outil de mesure d'audience, aucune donnée de vente ou de stock n'est envoyée. Le serveur de licences est hébergé chez Cloudflare.

Vos droits

Vous pouvez demander à consulter ou supprimer les informations d'enregistrement de votre boutique en nous contactant (coordonnées sur la page d'accueil). Vos données de boutique, elles, sont sous votre seul contrôle : supprimer l'application et son dossier de données les efface.

Ce site

Ce site est hébergé par GitHub Pages et charge ses polices depuis Google Fonts. Il interroge GitHub pour afficher la dernière version. Il n'utilise ni cookies ni outil de mesure d'audience.

بياناتك تبقى عندك

ما يبقى على حاسوبك

كل ما تُدخلينه في Glowdesk: المنتجات، الأسعار، الدفعات، المبيعات، الزبونات، المستخدمات ورموز PIN. تُحفظ هذه البيانات في ملف على حاسوبك (مع نسخها الاحتياطية) ولا تُرسل أبدًا إلى أي مكان آخر. رموز PIN مخزنة مشفّرة.

القليل الذي يُرسل

  • التسجيل المجاني (مرة واحدة): اسم المحل، اسم المالكة، الهاتف، الولاية، إصدار التطبيق ومعرّف تثبيت عشوائي. تُستعمل لإنشاء ترخيصك المجاني، لإعلامك بالجديد ولجمع ملاحظاتك.
  • عند فتح التطبيق: معرّف التثبيت، معرّف المحل والإصدار، للتحقق من الترخيص. بدون إنترنت، يعمل التطبيق بشكل عادي.
  • التحديثات: يسأل التطبيق GitHub عن وجود إصدار جديد. يرى GitHub عنوان IP للحاسوب كأي موقع آخر.

لا إعلانات، لا أدوات قياس، ولا تُرسل أي بيانات عن المبيعات أو المخزون. خادم التراخيص مستضاف لدى Cloudflare.
