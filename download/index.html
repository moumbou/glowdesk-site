Le téléchargement commence

Si rien ne se passe, cliquez ici pour télécharger Glowdesk-Setup.exe. Toutes les versions sont sur la page des versions.

Windows peut afficher « Windows a protégé votre ordinateur ». Cliquez sur Informations complémentaires, puis sur Exécuter quand même. Glowdesk n'a pas encore de certificat payant, mais le fichier vient toujours de la page officielle ci-dessus.
